# Code of Conduct

## Our pledge

We want participation in UNITY SENTINEL to be a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability, ethnicity,
sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race, religion,
or sexual identity and orientation.

## Expected behaviour

* Be respectful and precise. Critique code, not people.
* Assume good faith; ask before assuming a mistake is carelessness.
* Keep discussions technical and reproducible: commands, logs, fixtures.
* Respect project owners' time: search existing issues before opening a new one.
* Never publish someone's private data, credentials or proprietary project code.

## Unacceptable behaviour

* Harassment, insults, discriminatory language or personal attacks.
* Publishing others' private information without explicit permission.
* Deliberately submitting malicious code, hidden telemetry or backdoors.
* Dismissing a report of a safety problem in the change protocol.

## Scope

This code applies in repository issues, pull requests, discussions and any
community space where you represent the project.

## Enforcement

Report unacceptable behaviour to the maintainers via the security/contact channel
described in `SECURITY.md`. Reports are reviewed privately; maintainers may warn,
remove comments, or block contributors. Maintainers who do not follow this code
are subject to the same consequences.
